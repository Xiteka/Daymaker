# README images

These six screenshots show the actual Daymaker interface at a 390 × 844 viewport, captured on 16 November 2026 with fictional sample data. The preview used an isolated local fixture and made no account or database requests. No user's financial records, email addresses or credentials are included.

- `home.jpg`: dashboard and today's shift.
- `work.jpg`: work summary, completion slider and shift lists.
- `calendar.jpg`: work calendar and selected-day details.
- `expenses.jpg`: spending, monthly bills and transactions.
- `wishlist-folders.jpg`: custom wishlist folders.
- `wishlist.jpg`: savings progress and funded-item purchase action.
- `daymaker-banner.svg` / `.png`: README banner using the approved logo master.

The screenshots are documentation assets, not prefilled records in the app. They will need refreshing when the interface changes.
